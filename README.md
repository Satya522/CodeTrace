## 🚀 Quick Start Guide

Get CodeTrace running locally in less than 2 minutes.

```bash
# 1. Clone the repository
git clone https://github.com/Satya522/CodeTrace.git

# 2. Enter the directory
cd CodeTrace

# 3. Install dependencies
npm install

# 4. Copy the environment variables template
cp .env.example .env

# 5. Start the blazing-fast Turbopack dev server
npm run dev
```

> **Note:** Make sure you have **Node.js 18+** installed. Open `http://localhost:3000` to view the app!
